# Imaging Perturbation Dataset

This directory contains the underlying imaging perturbation dataset only.

## Content Scope

- Perturbation sample images (`*.jpg`).
- Initial-state images where available.
- `state_metadata.json`, which indexes each image by sample model type, sample group, perturbation type, state type, sample id, and relative image path.

Full detection/evaluation records are intentionally excluded from this task dataset directory. Those records belong to `documents/experimental_outcomes/different_disturbance_detection/`.
