# Teleoperation Dataset

The micromanipulation teleoperation dataset is hosted externally on Hugging Face.

Run the clone command from this directory so the dataset lands under:

```text
docs_public/documents/task_datasets/teleoperation_dataset/
```

```bash
git clone https://huggingface.co/datasets/404lzh/Data_of_Micromanipulation
```
