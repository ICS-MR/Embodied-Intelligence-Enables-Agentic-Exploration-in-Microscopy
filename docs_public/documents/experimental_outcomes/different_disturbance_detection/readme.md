## Data Description

This directory contains the test results for `different_disturbance_detection`. The results are organized by sample type.

## File Naming Conventions

The following suffixes are used in the file names:

| Suffix | Description |
|--------|-------------|
| `_BF`  | Brightfield image |
| `_FLU` | Fluorescence image |
| `_H`   | Image captured under high magnification |
| `_L`   | Image captured under low magnification |

For example, a file named `sample_name_BF_H` represents a brightfield image of the sample captured under high magnification.
